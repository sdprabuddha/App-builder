app.zip එක GitHub එකට දැම්මම ඔවුන්ගේ server එකෙන් APK එක හදලා දෙනවා.

  1. github.com එකේ account එකක් හදලා New repository (Public) එකක් හදන්න. (Phone එකේ නම් Chrome → Desktop site ON කරන්න.)
  2. Add file → Create new file → නම .github/workflows/build.yml කියලා type කරන්න → පහළ workflow එක Copy කරලා paste කරන්න → Commit.
  3. Add file → Upload files → app.zip එක (unzip නොකර) upload කරලා Commit.
  4. Actions tab එකේ build එක විනාඩි 5–8ක් යනවා. ඉවර වුණාම ඒකට ඇතුළු වී Artifacts → apk download කරලා unzip කර phone එකේ install කරන්න (“Install unknown apps” allow කරන්න).
